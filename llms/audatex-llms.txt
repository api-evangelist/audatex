# Audatex

> Audatex (a Solera company) publishes automotive claims, assessment and vehicle-inspection APIs for insurers, bodyshops and integrators: the AudaConnect WebAPI and BMS API (Audatex UK), the Intelligent Vehicle Inspection API Gateway, and the North American GIC and Dashboard Assignment integration APIs. REST with JSON/XML, OAuth 2.0, access granted by the Audatex service desk after application registration.

## Authentication

- [AudaConnect developers' guide](https://audaconnect.ax-aee.co.uk/AudaAPI.BMSAPI/home/help): OAuth 2.0 authorization-code (30-minute access tokens + refresh tokens), implicit, and refresh-token flows; authorize at https://audaconnect.ax-aee.co.uk/AudaAPI.Portal/OAuth20, token at https://audaconnect.ax-aee.co.uk/AudaAPI.Portal/OAuth20/token; scopes space-delimited (e.g. BMS.Basic BMS.Extended).
- [Register an application](https://audaconnect.ax-aee.co.uk/AudaAPI.BMSAPI/home/register): applications are created in the AudaConnect Portal, reviewed by Audatex, then client id/secret are emailed.
- [OpenID Connect discovery (North America)](https://dispatch-login-demo.audatex.com/.well-known/openid-configuration): identity server for the GIC and Dashboard Assignment APIs; token endpoint /connect/token, scope b2b.fnol.api.
